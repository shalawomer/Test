# Multimedia File Analyzer and Processor Using Python

## Project Idea
This project is a beginner-friendly multimedia systems practical program built in Python.  
It lets students explore **text, image, audio, and video processing** from one simple menu.

The program demonstrates:
- Basic text analytics and cleaning
- Image loading, channel inspection, resizing, noising, and blurring
- Audio waveform analysis, noise addition, FFT-based low-pass filtering, and SNR calculation
- Video metadata extraction and first-frame visualization

---

## Required Libraries
The project uses the following Python libraries:

- `opencv-python` (OpenCV) for image and video processing
- `matplotlib` for plotting images and waveforms
- `librosa` for audio loading and analysis
- `numpy` for arrays and mathematical operations
- `soundfile` for saving processed audio
- `collections.Counter` (built-in) for text word frequency

---

## How to Install Libraries
Run the following command:

```bash
pip install opencv-python matplotlib librosa numpy soundfile
```

---

## How to Run the Program
1. Place all required input files in the same folder as `multimedia_project.py`.
2. Open terminal in that folder.
3. Run:

```bash
python multimedia_project.py
```

4. Use the menu to choose:
   - Text Processing
   - Image Processing
   - Audio Processing
   - Video Information
   - Exit

---

## Required Files
Make sure these files are available in the project folder:

- `sample.txt`
- `image.jpg`
- `audio.wav`
- `video.mp4`

If any file is missing, the program will show an error message for that module.

---

## Output Files Generated by Program
Depending on what you run, the program may create:

- `cleaned_text.txt` (processed text)
- `compressed_image.jpg` (compressed image)
- `processed_audio.wav` (filtered audio)
